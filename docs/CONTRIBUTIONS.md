# 贡献说明

## 贡献一：专用困难负文本与测试协议

已有组合性测试集与本问题有关，但不一定精确控制句法相似度。本项目建立了针对性更强的构造协议：

1. 从caption解析依存三元组。
2. 识别ROLE_SWAP、ATTRIBUTE_BINDING_SWAP、SPATIAL_REVERSAL、PREDICATE_CONFLICT等可控扰动。
3. 使用结构化prompt生成只改变关键事实的负文本。
4. 拒绝空输出、原句复制、非英文、异常长度和严重重复。
5. 记录TED、依存边Jaccard、embedding similarity和NLI。
6. 按图像划分训练与held-out测试，避免用训练样本评价训练收益。

TopK构造相较random/all/none获得更高的句法保持与矛盾比例：10000条样本中contradiction为84.8%，平均TED为1.703，Jaccard为0.582，语义相似度为0.839。该结果说明目标三元组约束能产生更接近研究问题的负文本。

## 贡献二：三元组驱动的渐进式微调

框架不只要求模型选A/B，还要求输出可核验的方向敏感三元组。三阶段分别解决：

- SFT建立输出格式和显式关系推理习惯。
- DPO学习正确解释优于多类困难错误解释。
- RL直接优化答案与三元组联合目标，并用组内采样提供策略梯度信号。

5% RL实验将严格三元组命中率从DPO的16%提高到50%，三元组得分从0.291提高到0.712；答案准确率从88%变为86%。这表明结构能力明显增强，但答案保持仍是下一轮平衡实验的目标。

## 贡献边界

Image Route不是当前主结论成立的必要条件。它能提供视觉可恢复性排序，但不应被写成已经充分验证的核心监督。当前主要实证结论是“文本句法三元组监督有效”，而不是“Image Route本身已经最优”。
